# CampusDesk – Student Management Portal

A responsive web application for managing student records efficiently.

## 🚀 Features

- Add student records
- View student records
- Search students
- Edit student information
- Delete student records
- Clear student records
- Responsive design for mobile and desktop
- Local data persistence

## 🛠️ Technologies Used

- React
- TypeScript
- HTML
- CSS
- Vite
- ## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code or another code editor.
3. Install the required dependencies.
4. Start the development server.
5. Open the local URL shown in the terminal.

## 📱 Project

CampusDesk provides a simple and user-friendly interface for maintaining student information such as:

- Student Name
- Roll Number
- Department
- Email
- Phone Number
