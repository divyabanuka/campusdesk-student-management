# CampusDesk – Student Management Portal

A responsive web application for managing student records efficiently.

## 🚀 Features

- Add student records
- View student records
- Search students
- Edit student information
- Delete student records
- Clear student records
- Responsive design for mobile and desktop
- Local data persistence

## 🛠️ Technologies Used

- React
- TypeScript
- HTML
- CSS
- Vite

## 📱 Project

CampusDesk provides a simple and user-friendly interface for maintaining student information such as:

- Student Name
- Roll Number
- Department
- Email
- Phone Number
